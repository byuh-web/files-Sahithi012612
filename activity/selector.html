List out the different ways to select an item.

Tag (p), Class (.class), ID (#id), Attribute (input[type="text"]), Universal (*).

What is the difference between an ID and a Class?

ID vs Class: ID is unique for one element, while Class can be used for multiple elements.

What is the difference between a SPAN tag and a DIV tag?

SPAN vs DIV: SPAN is an inline element, while DIV is a block element.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

DIV vs HEADER/MAIN/FOOTER: DIV is a generic container, while HEADER, MAIN, and FOOTER are semantic structure elements.

What are the different ways to select a color?

Different ways to select colors: Color name (red), HEX (#ff0000), RGB (rgb()), RGBA (rgba()), and HSL (hsl()).
